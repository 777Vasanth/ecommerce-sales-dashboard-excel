# E-Commerce Sales Dashboard using Excel

## Project Overview
This project presents an interactive E-Commerce Sales Dashboard created using Microsoft Excel. The dashboard is designed to analyze sales performance, customer behavior, product trends, and revenue insights using Excel data analysis and visualization techniques.

The project focuses on transforming raw e-commerce data into meaningful business insights through pivot tables, charts, KPIs, slicers, and dashboard reporting.

---

# Objectives
- Analyze overall sales performance
- Track revenue and profit trends
- Identify top-performing product categories
- Understand customer purchasing behavior
- Monitor key business KPIs
- Create an interactive dashboard for business reporting

---
